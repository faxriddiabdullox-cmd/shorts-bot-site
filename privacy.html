Privacy Policy

Last updated: 2026-09-07

shorts-bot is a personal automation tool that generates and uploads short videos to the owner's own YouTube channel ("SPORT CAR").

What data the application accesses

  • OAuth tokens (scopes youtube.upload, youtubepartner) of the owner's own Google account only.
  • No other users' data is collected, stored, or processed.

How data is stored

  • OAuth tokens are stored locally on the owner's computer and as encrypted secrets in GitHub repository settings (GitHub Actions encrypted secrets).
  • Video files are uploaded to YouTube via the official YouTube Data API v3.

Data sharing

No personal data is shared with, sold to, or transferred to any third parties.
